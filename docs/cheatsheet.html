What the lights mean

Green = key All normal
Red = key SOCD armed, or NKRO off
Green Caps Caps Lock on
Blue N Num Lock on
Red F9 Scroll Lock on
Magenta WASD SOCD armed
Amber K NKRO off (while Fn held)
Blinking red About to wipe — let go now
Both side bars stay the baseline colour. Every indicator sits on the key it refers to. The = key has a dead blue LED channel, so it is driven red/green only — that is why it is the status light.

Fn+Esc — the two resets

TapLighting back to defaults. Safe
Hold ~1.5sBoard blinks red — warning
Let go on redNothing happens. Escape hatch
Hold 2s+Wipes EEPROM: VIA remaps, lighting, all
The red flash starts half a second before the wipe point on purpose — see it, let go, nothing is lost.

Flashing — the trap

VIA means the board types from EEPROM, not from the firmware. Flash a changed keymap normally and nothing happens — it keeps using the stored one. Always mass-erase:

BootloaderFn+PrtSc
Thendfu-util -a 0 -d 0483:df11 -s 0x08000000:mass-erase:force -D firmware.bin
